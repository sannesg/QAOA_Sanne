QAOA Project Structure and Overview
1. Folder Structure
Folder: qaoa
This is the main package implementing the Quantum Approximate Optimization Algorithm (QAOA) and its components. It is organized into several subfolders and files:

File: qaoa.py: Main QAOA algorithm class and orchestration logic.
Sub folder: problems/: Contains problem definitions (e.g., MaxCut, QUBO, Exact Cover, Portfolio).
Sub folder: mixers/: Contains mixer Hamiltonians (e.g., X-mixer, XY-mixer, Grover-mixer).
Sub folder: initialstates/: Contains initial state preparations (e.g., Plus, Dicke, LessThanK).
Sub folder: util/: Utility functions and classes (e.g., statistics, bit-flip, post-processing).
File: __init__.py: Imports main classes and submodules for easy access.

Folder: examples
This folder contains Jupyter notebooks and scripts demonstrating how to use the QAOA package for various problems, as well as plotting routines.


2. File and Class Overview
File: qaoa.py
Purpose: Implements the main QAOA class, which orchestrates the construction, execution, and optimization of QAOA circuits.

Key Classes:

Class: QAOA:

Attributes: problem, mixer, initialstate, backend, optimizer, shots, cvar, parameterized_circuit, optimization_results, etc.
Main Methods:
__init__: Initializes QAOA with problem, mixer, initial state, and backend.
createParameterizedCircuit(depth): Builds the parameterized QAOA circuit for a given depth.
sample_cost_landscape(angles): Samples the cost landscape over a grid of angles.
optimize(depth): Runs classical optimization to find optimal angles.
get_Exp(depth), get_Var(depth), get_gamma(depth), get_beta(depth): Extracts results for each depth.
hist(angles, shots): Returns measurement histograms.
loss(angles): Computes the loss function for optimization.
measurementStatistics(job): Processes measurement results.
get_optimal_solutions(): Returns the best solutions found.
OptResult:

Stores optimization results for each depth, including angles, expectation values, variances, and best solutions.


Folder: problems
Purpose: Contains problem classes, each defining a cost function and quantum circuit for a specific combinatorial optimization problem.

Key Files and Classes:

File: base_problem.py

Problem (abstract): Base class for all problems. Requires create_circuit and cost methods.
maxkcut_binary_powertwo.py

Class: MaxKCutBinaryPowerOfTwo: For Max k-Cut with k a power of two, using binary encoding.
Methods: is_power_of_two, validate_parameters, construct_colors, create_edge_circuit, create_edge_circuit_fixed_node, getPauliOperator.
maxkcut_binary_fullH.py

Class: MaxKCutBinaryFullH: General Max k-Cut using binary encoding and full Hamiltonian.
Methods: validate_parameters, construct_colors, apply_N, add_equalize_color, create_edge_circuit, create_edge_circuit_fixed_node, getPauliOperator.
maxkcut_one_hot_problem.py

Class: MaxKCutOneHot: Max k-Cut using one-hot encoding.
Methods: binstringToLabels, cost, create_circuit.
qubo_problem.py

Class: QUBO: General Quadratic Unconstrained Binary Optimization problem.
Methods: cost, create_circuit, createParameterizedCostCircuitTril.
exactcover_problem.py

Class: ExactCover: Exact Cover problem.
Methods: cost, create_circuit, isFeasible, __exactCover.
portfolio_problem.py

Class: PortfolioOptimization: Portfolio optimization as a QUBO.
Methods: cost_nonQUBO, isFeasible, __str2np.
graph_problem.py

Class: GraphProblem: Base class for graph-based problems.

Key Files and Classes:

Folder: util

Key Files and Classes:

4. How to Use and Extend
To create a QAOA instance:
Import the relevant problem, mixer, and initial state, then instantiate QAOA:
*code start*
from qaoa import QAOA, problems, mixers, initialstates
qaoa = QAOA(
    initialstate=initialstates.Plus(),
    problem=problems.MaxKCutBinaryPowerOfTwo(G=G, k_cuts=2),
    mixer=mixers.X()
)
*code end*

To run optimization:
*code start*
qaoa.optimize(depth=1)
*code end*

To sample the cost landscape:
*code start*
qaoa.sample_cost_landscape()
*code end*

To extract results:
*code start*
qaoa.get_Exp(depth=1)
qaoa.get_gamma(depth=1)
*code end*

To plot results:
Use functions from plotroutines.py, e.g., plot_E(qaoa).

To add a new problem, mixer, or initial state:
Inherit from the relevant base class in base_problem.py, base_mixer.py, or base_initialstate.py and implement the required methods.
